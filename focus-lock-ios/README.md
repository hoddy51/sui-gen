# FocusLock（自分用アプリロック）

iPhone の「スクリーンタイム API」を使った、自分専用のアプリロック＆カウントアプリです。
データはすべて iPhone の中だけに保存され、サーバーは使いません。

## できること

| 機能 | 内容 |
|---|---|
| 集中モード | 15〜120分のあいだ、選んだアプリをロック。円形タイマー付き |
| スケジュールロック | 毎日決まった時間（例: 23:00〜7:00、平日のみ等）に自動ロック |
| 1日の利用上限 | 「SNSは1日30分まで」のように、上限に達したらその日はロック |
| 解除のハードル | 待ち時間（アプリを離れるとやり直し）→ 理由の入力 → 1日の回数制限 |
| ロック中は設定変更不可 | ロック中にブロック対象を外す・スケジュールを消すといった抜け道を防止 |
| ブロック画面 | 開こうとするとロック理由と「今日ここに来た回数」「我慢できた回数」を表示 |
| カウント | 開こうとした回数・我慢できた回数・解除した回数・集中した分数・連続日数 |
| 記録 | 7日間のグラフ、解除理由の履歴、iOS のスクリーンタイム（利用時間・持ち上げ回数・通知数） |

## 必要なもの

- **Mac**（Xcode 16 以降）
- **Apple Developer Program（年 99 ドル）**
  スクリーンタイム API（Family Controls）は、無料の Apple ID（Personal Team）では使えません。
  ※ 自分の iPhone に入れて使うだけなら、Apple への追加申請は不要です（開発用の権限で動きます）。
- iOS 17 以降の iPhone（シミュレーターではロックが動かないので実機必須）

## セットアップ手順

1. XcodeGen を入れる
   ```bash
   brew install xcodegen
   ```
2. `project.yml` の先頭の3行を自分用に書き換える
   ```yaml
   DEVELOPMENT_TEAM: "ABCDE12345"            # Apple Developer の Team ID
   BASE_BUNDLE_ID: com.yourname.focuslock     # 自分だけのID
   APP_GROUP_ID: group.com.yourname.focuslock # "group." + 上のID
   ```
   Team ID は https://developer.apple.com/account の「メンバーシップの詳細」で確認できます。
3. プロジェクトを生成して開く
   ```bash
   cd focus-lock-ios
   xcodegen generate
   open FocusLock.xcodeproj
   ```
4. iPhone を Mac につなぎ、iPhone 側で「設定 → プライバシーとセキュリティ → デベロッパモード」をオン
5. Xcode 上部で自分の iPhone を選んで ▶︎ 実行
   - Signing でエラーが出たら、各ターゲット（5つ）の「Signing & Capabilities」で Team を選び、
     「App Groups」「Family Controls」が付いていることを確認してください
6. アプリ起動 →「許可してはじめる」→ スクリーンタイムへのアクセスを許可

`project.yml` を変更したら、もう一度 `xcodegen generate` を実行してください。

## 使い方

1. **ブロック**タブ → 「ブロックするアプリ」でロックしたいアプリ（SNS、動画など）を選ぶ
2. **ホーム**で時間を選んで「集中する」
3. 必要なら**スケジュールロック**や**1日の利用上限**を追加
4. **設定**で解除のハードル（待ち時間・理由・回数）を好みの厳しさに

ロック中にアプリを開くとブロック画面が出ます。
- 「閉じる（我慢する）」… 我慢できた回数 +1
- 「解除をリクエスト」… 通知が届くので、タップして FocusLock で解除の手続き

## もっと強力にしたいとき

このアプリは自分で削除したり、設定アプリでスクリーンタイムの許可を外したりすれば止められてしまいます。
本気で防ぎたい場合は、iPhone の「設定 → スクリーンタイム → スクリーンタイム・パスコードを使用」をオンにして、
**パスコードを家族や友人に設定してもらう**のがおすすめです。

## 構成

```
focus-lock-ios/
├── project.yml                      XcodeGen のプロジェクト定義
├── App/                             本体アプリ（SwiftUI）
│   ├── AppModel.swift               画面の状態と操作
│   ├── ActivityScheduler.swift      時刻に合わせた監視の登録
│   └── Views/                       ホーム・ブロック・記録・設定・解除画面
├── Shared/                          本体と拡張で共有するコード
│   ├── Models.swift                 データ型
│   ├── SharedStore.swift            App Group 内に保存
│   ├── ShieldController.swift       「いま何をロックするか」を計算してロック
│   └── Notifier.swift               通知
├── MonitorExtension/                時刻になったらロック／解除（アプリが閉じていても動く）
├── ShieldConfigurationExtension/    ブロック画面の見た目
├── ShieldActionExtension/           ブロック画面のボタンの処理
├── ReportExtension/                 スクリーンタイムの表示
└── ReportShared/                    本体とレポート拡張の共通定義
```

## 制約・注意点

- **15分ルール**: iOS の監視は最低15分必要なため、集中モードと一時解除は15分以上にしています。
- **「開こうとした回数」は目安**: iOS がブロック画面を作り直すたびに数えるため、多少ずれることがあります。
- **スクリーンタイムのデータ**（利用時間・持ち上げ回数）はプライバシー保護のため表示専用で、
  アプリ本体ではこの数値を使った計算ができません（Apple の仕様）。
- 日付をまたぐスケジュール（23:00〜7:00 など）は1つの監視として登録しています。
  もし iOS のバージョンによって動かない場合は、23:00〜23:59 と 0:00〜7:00 の2つに分けて登録してください。
- このコードは Linux 環境で書いたため、まだ Xcode でビルドしていません。最初のビルドで小さなエラーが
  出る可能性があります。エラーメッセージを貼ってもらえれば直します。
